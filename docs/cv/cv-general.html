Selected Projects

Kaskor ASR

Released 2026 · Khmer speech recognition

ML pipeline, evaluation, and release tooling

  • Built a reproducible Khmer speech-to-text pipeline on Whisper-small (~86k audio samples); best checkpoint reports 3.74% CER, 57.2% WER (secondary), 0.0356 eval loss on a validation split whose speakers are also in training.
  • Chose Character Error Rate as the primary metric because Khmer does not reliably separate words with spaces; normalized text and verified 16 kHz audio so evaluation stays honest.
  • Shipped a pip-installable CLI (files, folders, reference text, microphone) under MIT; datasets and model weights are excluded intentionally.

Stack  Python · PyTorch · Hugging Face · Whisper · Torchaudio · CER evaluation

Chomkar Decision Grid

Released 2026 · Agritech decision intelligence

Framework design, deterministic engine, and Claude workflow

  • Designed an open-source engine that assembles smallholder farmer lots to satisfy buyer orders, with auditable prices, allocations, and route-risk scores.
  • Deterministic Python core with 62 unit tests and CI; an independent audit stage re-derives payouts, coverage, and the winning score — “cannot fulfill” is a valid, tested output.
  • Generates bilingual Khmer/English reports that end with an explicit human-approval checklist; all bundled data is synthetic by design.

Stack  Python stdlib · unit tests · Claude Code · bilingual reports · decision audit

Chomkar OrderLoop

Field-validated 2026 · Market coordination for farmers

ML roadmap, business analysis, and field validation

  • Interviewed ~30 bok choy farmers in Kang Meas, Kampong Cham (with the team) to validate a buyer-first order loop that coordinates farmer commitments into one documented cooperative lot.
  • Concept placed Top 2 at TSC Turing Hackathon Cycle 10 (Market Access for Farmers); pilot thesis is deliberately bounded to one recurring buyer, one cooperator, and 30–100 farmers.

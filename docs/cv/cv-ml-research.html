Machine-Learning Projects

Kaskor ASR

Released 2026 · Khmer speech recognition · KM-ASR-00

ML pipeline, evaluation, and release tooling

  • Fine-tuned Whisper-small into a reproducible Khmer speech-to-text pipeline over ~86k audio samples; best published checkpoint reports 3.74% CER, 57.2% WER, 0.0356 eval loss on the validation split, greedy decoding. Corrected down from a published 17.48% after finding a 225-token decode cap that truncated the model's output during evaluation; splits share speakers, so this is not a new-speaker estimate.
  • Selected Character Error Rate as the primary metric because Khmer does not reliably separate words with spaces, and documented WER as a secondary signal that should not be read as the main quality measure.
  • Controlled preprocessing so evaluation differences are not hidden inside it — text normalization plus verified 16 kHz resampling before training and scoring.
  • Documented the full path end to end: dataset inspection, manifest building, resampling, splitting, training, evaluation, export, and inference; raw audio and weights stay outside Git while manifests, scripts, and evaluation logic are versioned.
  • Released a pip-installable CLI (files, folders, reference text, optional microphone) under MIT. Stated limitations: early model, not production-grade for every speaker or acoustic environment; reproduction needs source audio and compute.

Chomkar Decision Grid

Released 2026 · Decision intelligence · agritech

Framework design, deterministic engine, and AI workflow

  • Built a decision framework (Detect → Evaluate → Recommend → Act) where a deterministic Python core owns allocations, prices, and risk scores, and the language model only explains results it did not compute.
  • 62 unit tests and CI, plus an independent audit stage that re-derives payouts, allocation limits, order coverage, and the winning score; designed failure cases make “cannot fulfill” a valid, tested output.
